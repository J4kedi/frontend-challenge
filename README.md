# Kurio — Marketplace de NFTs

Solução do [desafio frontend da Jungle Gaming](docs/challenge.md). React + TypeScript
com TanStack Router e Query, Axios, Socket.IO, Tailwind, shadcn/ui, MSW, Playwright
e Lighthouse.

> Documento em construção: setup, cenários e comandos completos entram nos próximos commits.

## Rodar localmente

```bash
pnpm install
pnpm dev          # http://localhost:5173 com a camada de mocks ligada
```
